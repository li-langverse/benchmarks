# /agent-briefing

Run **preflight scripts** for Cursor agents (no reasoning in scripts).

```bash
cd benchmarks
./scripts/agent-preflight.sh
cat data/latest/agent-briefing.json
```

Then run the recommended agent from [cursor-agent-architecture.md](../../docs/ecosystem/cursor-agent-architecture.md) (paste `.cursor/automations/<agent>.md` in Cursor Automations or continue in this chat).
