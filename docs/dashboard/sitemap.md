# Benchmark portal — sitemap

Quick route reference for the Li scientific benchmark portal. Full layout, components, and tokens: [design-system.md](./design-system.md).

**Base:** `https://li-langverse.github.io/benchmarks/`

| Path | Page |
|------|------|
| `/` | Overview — bento grid, tier strip, honesty strip |
| `/pillar/[id]` | Pillar drill-down (`proof`, `easy`, `fast`, `ai`, `hpc`) |
| `/bench/[id]` | Single benchmark detail + history |
| `/matrix` | Full benchmark matrix (filters, table) |
| `/history` | Ingest / run history index |
| `/proofs` | Proof library — catalog vs Lean, local human votes |
| `/packages/[pkg]` | Package freshness (`lip`, `lit`, `lis`, …) |

**Global nav (target):** Overview · Matrix · History · Proofs · Packages

**Cross-links (external):** lic catalog paths, lis tier-5 HTTP, roadmap vision doc — open in new tab.

**Demo recording:** [demo-video-script.md](./demo-video-script.md), [demo-storyboard.html](./demo-storyboard.html), [`scripts/record-dashboard-demo.sh`](../../scripts/record-dashboard-demo.sh).
