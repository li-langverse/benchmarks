### Search

- Material search with `search.suggest` + `search.highlight`; index at `site/search/search_index.json`.
- Gaps vs [rustdoc search UX](https://doc.rust-lang.org/stable/rustdoc/read-documentation/search.html): no type-signature search (N/A for prose docs), no **`?` shortcut overlay**, no **`S`/`/` focus** documented on site.
- With `navigation.instant`, search index persists across navigation ([Material instant loading](https://squidfunk.github.io/mkdocs-material/setup/setting-up-navigation/#instant-loading)) — ensure theme ≥ 9.5.5 if regressions seen ([issue #6275](https://github.com/squidfunk/mkdocs-material/issues/6275)).

### Mobile TOC & navigation

- Features: `navigation.tabs`, `navigation.tabs.sticky`, `navigation.sections`, `toc.follow` (not `toc.integrate`).
- On viewports &lt; 1220px, tabs collapse to drawer; TOC in drawer needs **menu → TOC** ([Material mobile behavior](https://github.com/squidfunk/mkdocs-material/discussions/6089), [TOC visibility #5935](https://github.com/squidfunk/mkdocs-material/issues/5935)).
- **Recommendation:** add “On this page” jump links in long handbook pages OR evaluate `toc.integrate` for handbook-only (conflicts with tabs per Material docs).
