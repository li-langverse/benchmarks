### Search

- Material search with `search.suggest` + `search.highlight`; index at `site/search/search_index.json`.
- **Built-in shortcuts** (Material global mode): `F`, `S`, `/` open search; arrow keys navigate results ([Material site search](https://squidfunk.github.io/mkdocs-material/setup/setting-up-site-search/)).
- **Gap vs [mdBook](https://rust-lang.github.io/mdBook/guide/reading.html):** no `?` help overlay documenting shortcuts on-site (mdBook documents `S`, `/`, `?` in chrome).
- **Stale index on live:** 248 entries vs 2801 local — search omits new handbook sections until publish fixed.
- **SOTA add-on:** `navigation.instant.prefetch` not enabled (experimental hover prefetch per [Material instant loading](https://squidfunk.github.io/mkdocs-material/setup/setting-up-navigation/#instant-loading)).

### Mobile TOC & navigation

- Features: `navigation.tabs`, `navigation.tabs.sticky`, `navigation.sections`, `toc.follow` (not `toc.integrate`).
- Tabs collapse to drawer below **1220px**; TOC remains separate on mobile ([Material navigation tabs](https://squidfunk.github.io/mkdocs-material/setup/setting-up-navigation/#navigation-tabs)).
- **`toc.integrate`** would merge TOC into nav drawer on desktop but is **incompatible** with `navigation.tabs.sticky` and `navigation.indexes` ([Material TOC integration](https://squidfunk.github.io/mkdocs-material/setup/setting-up-navigation/#navigation-integration)).
- **Recommendation:** “On this page” jump links on long handbook pages; evaluate handbook-only `toc.integrate` pilot after tab/sticky conflict resolved.
