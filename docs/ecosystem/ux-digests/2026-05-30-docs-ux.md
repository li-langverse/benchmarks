## Executive summary

- **Harness rubric:** static `ux_audit` **pass** (min 0.70); manual journey audit flags **live-site friction** (404s, 5-tab nav) not scored by the static adapter.
- **P0 publish drift (unchanged):** Live Pages still **5** nav tabs vs **12** local; search index **248** vs **2801**; `guide/hello-world/` and `ecosystem/overview/` **404** on live ([#403](https://github.com/li-langverse/lic/issues/403)) — breaks first-visitor reading path.
- **Diátaxis IA gap:** **11** `language/*.md` reference pages nested under **Game development** tab; **Language handbook** has only 5 overview pages ([#422](https://github.com/li-langverse/lic/issues/422)).
- **Onboarding triple-entry:** Home cards, **Getting started** tab, and **Guide → Hello world** all route new readers to the same tutorial — cognitive load without a single canonical “start here” path (Diátaxis tutorial vs how-to boundary).
- **SOTA gaps vs MkDocs Material:** `search.suggest` + `search.highlight` enabled; missing `search.share`, `navigation.instant.prefetch`, and `toc.integrate` ([Material search](https://squidfunk.github.io/mkdocs-material/setup/setting-up-site-search/), [Material navigation](https://squidfunk.github.io/mkdocs-material/setup/setting-up-navigation/)).
- **Mobile TOC:** `toc.follow` on; mobile drawer requires **two taps** to reach in-page anchors (960–1219px band shows TOC behind overlay — [Material #5935](https://github.com/squidfunk/mkdocs-material/issues/5935)); acceptable Material default but worth documenting in contributor guide.
- **Competitor benchmark (rustdoc):** [Rust doc search](https://doc.rust-lang.org/stable/rustdoc/read-documentation/search.html) exposes `S`/`/` focus, `?` help, and type-signature search — Li Material search lacks in-doc shortcut help overlay.
- **Briefing signal:** 10 repos without live docs per ecosystem audit — separate `docs_maintainer` wave; this pass focuses on canonical `lic-docs` journey.
