## C. Web spot-check (2026-05-17)

**PETSc + Kokkos PDE stack.** Production exascale PDE codes integrate PETSc solvers with Kokkos for GPU portability (e.g. `MATSOLVERKOKKOS`, batched Jacobi). **Li gap:** tier-2 physics and `li-std-physics-*` stubs lack implicit solvers, AMG, and distributed meshes; benchmarks rely on shared C cores. **lic#14**, **lic#15**.

**Stdlib numerics / GEMM roadmaps.** Ecosystems (NumPy NEPS, Rust SVE/SME goals, JS stdlib BLAS track) treat SIMD GEMM and vendor BLAS as table stakes. **Li gap:** Phase **2i** matrix `@` deferred; **7e** SIMD matmul deferred; **horner_pure_li** 88× shows pure-Li scalar path not competitive. **numerics_research** + lic#9/#11.

**Kokkos vs OpenMP portability.** Recent HPC studies favor Kokkos views + backends across vendors; OpenMP offload works but multi-GPU structured grids can lag. **Li gap:** `std.execution.decorators` is policy AST only — **lic#15**.

**FFTW vs vendor FFT.** FFTW remains the reference; MKL/vendor FFT often faster on large transforms. **Li gap:** no FFT catalog row — **benchmarks#18**.
