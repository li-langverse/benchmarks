### C. Web spot-check (2026-05-30)

**PETSc + Kokkos PDE stack.** Production stacks mix PETSc solvers with Kokkos execution spaces; GPU assembly favors `MatSetPreallocationCOO` / `MatSetValuesCOO` and stream-aligned `PetscGetKokkosExecutionSpace()` rather than legacy `MatSetValues` on device. **Li gap:** no KSP/SNES/DM/time-integrator surface; tier-2 physics uses shared C cores and scaffold packages — lic [#117](https://github.com/li-langverse/lic/issues/117), [#14](https://github.com/li-langverse/lic/issues/14).

**Stdlib numerics / SIMD roadmaps.** Go 1.26 `simd/archsimd` and a planned portable `simd` layer; C++26 `std::simd` (P1928) — ecosystems treat SIMD as layered stdlib, not ad-hoc intrinsics only. **Li gap:** PH-2i/7e partial; matmul near 1.02–1.06× C++ — continue codegen/proof work — lic [#27](https://github.com/li-langverse/lic/issues/27), [#33](https://github.com/li-langverse/lic/issues/33).

**Kokkos vs OpenMP portability.** Kokkos P≈0.9 vs prescriptive OpenMP ≈0.45 on multi-vendor GPU/CPU in recent studies; OpenMP target backends often lag native CUDA/HIP unless tuned per platform. **Li gap:** `std/execution/decorators.li` has no memory spaces, views, or backend selection — lic [#15](https://github.com/li-langverse/lic/issues/15).

**FFTW vs vendor FFT roofline.** CPU FFTW wins below ~1 MiB inputs; GPU cuFFT crosses over near 2^16 elements; roofline turns compute-bound → memory-bound at scale. **Li gap:** tier-1 FFT row mostly unmeasured in matrix (`fft_1d_fixed` near-threshold only); catalog FFT evidence — benchmarks [#18](https://github.com/li-langverse/benchmarks/issues/18), [#26](https://github.com/li-langverse/benchmarks/issues/26), [#52](https://github.com/li-langverse/benchmarks/issues/52).
