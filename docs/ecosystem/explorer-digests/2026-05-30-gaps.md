### C. Web spot-check (2026-05-30)

**PETSc + Kokkos PDE stack.** Exascale production stacks unify PETSc solvers (KSP/SNES/DM) with Kokkos execution spaces, Kokkos-Kernels math, GPU-native COO assembly, and stream-shared dispatch via `PetscGetKokkosExecutionSpace()`. **Li gap:** no implicit PDE solver surface; tier-2 physics uses shared C kernels and scaffold packages — lic [#117](https://github.com/li-langverse/lic/issues/117), [#14](https://github.com/li-langverse/lic/issues/14).

**Stdlib numerics / SIMD roadmaps.** Go 1.26 `simd/archsimd`, C++26 `std::simd`, and Java Vector API (JEP 508) treat portable SIMD as a first-class stdlib layer with low/high APIs. **Li gap:** PH-2i/7e partial — tier-1 green but near-threshold on matmul; needs sustained codegen proof, not threshold tweaks — lic [#27](https://github.com/li-langverse/lic/issues/27), [#33](https://github.com/li-langverse/lic/issues/33).

**Kokkos vs OpenMP portability.** Plasma PIC studies (2024–2025) report Kokkos P≈0.9 vs prescriptive OpenMP ≈0.45 on multi-vendor GPU/CPU; OpenMP target backends lag native Kokkos CUDA/HIP unless compiler extensions apply. **Li gap:** `std/execution/decorators.li` has no memory spaces, views, or backend selection — lic [#15](https://github.com/li-langverse/lic/issues/15).

**FFTW vs vendor FFT roofline.** CPU FFTW wins below ~2^16 elements; GPU cuFFT crosses over near 65k points; roofline shifts from compute-bound to memory-bound at scale. **Li gap:** `fft_1d_fixed` near-threshold at 1.007× but no dedicated tier-1 FFT catalog row with vendor roofline — benchmarks [#18](https://github.com/li-langverse/benchmarks/issues/18), [#26](https://github.com/li-langverse/benchmarks/issues/26), [#52](https://github.com/li-langverse/benchmarks/issues/52).
