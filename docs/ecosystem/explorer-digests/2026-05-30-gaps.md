**Stdlib numerics / SIMD roadmaps.** Go 1.26 `simd/archsimd`, C++26 `std::simd`, and Java Vector API all treat portable SIMD GEMM/reductions as baseline language surface. **Li gap:** PH-2i matrix `@` and PH-7e blocked matmul still red at 1.33–1.55× — compiler lowering + linalg surface, not catalog threshold tweaks (**lic#27**, **lic#33**).

**Kokkos vs OpenMP portability.** Recent plasma-physics studies show Kokkos achieving broader vendor portability than raw OpenMP target offload; OpenMP performance varies sharply by compiler construct choices. **Li gap:** `@parallel` / `@vectorized` decorators parse to policy AST without execution-space or memory-space lowering — **lic#15**, **lic#109**.

**FFTW vs vendor FFT roofline.** FFTW remains the reference implementation but vendor libraries (MKL, PocketFFT, cuFFT) often win on specific sizes; roofline analysis treats FFT as memory-bound. **Li gap:** no tier-1 FFT micro-bench in catalog harness — **benchmarks#18**, **#26**, **#52**; add before claiming G-math FFT slice.
