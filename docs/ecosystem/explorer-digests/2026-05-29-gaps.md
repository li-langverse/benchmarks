### C. Web spot-check (2026-05-29)

**PETSc + Kokkos PDE stack.** PETSc 3.25 treats Kokkos as a first-class GPU portability layer (Vec/Mat Kokkos views, `PCBJKOKKOS` batched preconditioners); exascale teams avoid duplicated CUDA/HIP sources by routing through Kokkos-Kernels. **Li gap:** no KSP/SNES/DM/time-integrator surface; tier-2 physics uses shared C cores and package stubs — implicit/AMG/distributed mesh story absent (**lic#117**, **lic#14**).

**Stdlib numerics / SIMD roadmaps.** Industry direction is performance-portable SIMD (Highway, dynamic dispatch) plus BLAS-shaped std APIs (C++ P1673 `mdspan` linalg). NumPy 2 / Rust SIMD crates treat GEMM-level ops as baseline. **Li gap:** PH-2i matrix `@` and PH-7e pure-Li SIMD matmul still partial; red tier-1 rows need compiler lowering, not catalog edits (**lic#27**, **lic#33**).

**Kokkos vs OpenMP portability.** 2024–2025 studies show Kokkos/RAJA often match native GPU performance across vendors; OpenMP target offload is portable but frequently below native on complex GPU kernels. **Li gap:** `std.execution.decorators` is policy/MIR scaffolding without memory spaces or backend selection — **lic#15**, **lic#109**.

**FFTW / vendor FFT roofline.** FFT micro-benches and roofline comparisons remain standard for tier-1 numerics catalogs. **Li gap:** no shipped `num_fft_r2c` pure-Li proof path in explorer rubric — **benchmarks#18**, **#52**, **#26** (existing).
