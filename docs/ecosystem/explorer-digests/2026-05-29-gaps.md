### C. Web spot-check (2026-05-29)

**PETSc + Kokkos PDE stack.** PETSc 3.25+ integrates Kokkos as a first-class GPU backend: shared `Kokkos::View` data, `PetscGetKokkosExecutionSpace()` for stream-aligned `parallel_for`, and device preconditioners such as PCBJKOKKOS ([PETSc GPU roadmap](https://petsc.org/release/overview/gpu_roadmap/), [exascale PETSc+Kokkos paper](https://arxiv.org/html/2406.08646v1)). **Li gap:** tier-2 physics uses shared C kernels and package stubs, not KSP/SNES/DM — route implicit PDE work to **sim** + **lic#117**, not ad-hoc lic monolith codegen without `plan-approved`.

**Stdlib numerics roadmaps.** Ecosystem languages flatten generic numeric hierarchies (Rust `std::num` reform) while pushing advanced LA to packages; NSA/CISA memory-safety roadmaps elevate proved, safe numerics stacks. **Li gap:** **2i**/**7e** must close **G-math** in the same PR as handbook claims — **lic#27**, **lic#33**; do not mirror Eigen’s full expression-template surface in `std/`.

**Kokkos vs OpenMP portability.** Kokkos scores higher performance portability (P≈0.91) than prescriptive OpenMP on GPUs in recent studies; OpenMP target can be 30–70% of native HIP/CUDA on some kernels ([Kokkos vs OpenMP portability paper](https://eprints.whiterose.ac.uk/id/eprint/235565/)). **Li gap:** `std/execution/decorators.li` is policy without memory spaces — **lic#15**, **lic#109**.

**Eigen GEMM / constexpr.** Eigen routes GEMM through BLAS (`dgemm`/`sgemm`) and is expanding constexpr for small fixed-size ops, not full GEMM at compile time ([Eigen MR 881](https://gitlab.com/libeigen/eigen/-/merge_requests/881)). **Li gap:** Li tier-1 matmul must prove loop implementations vs closed-form `ensures` (**P-linalg**, **G-lean**) before claiming Eigen-class performance — **lic#27**.
