**PETSc + Kokkos PDE stack.** PETSc 3.25 routes Vec/Mat through Kokkos views and device-native preconditioners (`PCBJKOKKOS`), using Kokkos-Kernels as a vendor-neutral GPU layer (Argonne exascale narrative). **Li gap:** no KSP/SNES/DM/time-integrator surface; tier-2 physics uses shared C cores and package stubs — implicit/AMG/distributed mesh absent (**lic#117**, **lic#14**).

**Stdlib numerics / SIMD roadmaps.** JVM Vector API, C++26 `std::simd`, and Go `simd` experiment converge on portable SIMD + BLAS-shaped micro-kernels for GEMM. **Li gap:** PH-2i matrix `@` and PH-7e pure-Li SIMD matmul still partial; red tier-1 rows need compiler lowering (**lic#27**, **lic#33**).

**Kokkos vs OpenMP portability.** Leadership-class studies (2024–2025) show Kokkos/RAJA often match native GPU backends; OpenMP target offload frequently trails (≈30–57% of native in cited Kokkos OpenMPTarget studies). **Li gap:** `std.execution.decorators` lacks memory spaces and backend selection — **lic#15**, **lic#109**.

**FFTW / vendor FFT roofline.** FFT benchmarks follow inverse-roofline curves (compute-bound small N, memory-bound large N); vendor libs win peak, FFTW wins portability. **Li gap:** no tier-1 pure-Li FFT proof path — **benchmarks#18**, **#52**, **#26**.
