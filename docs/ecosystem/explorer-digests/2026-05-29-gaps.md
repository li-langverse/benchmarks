### C. Web spot-check (2026-05-29)

**PETSc + Kokkos PDE stack.** PETSc 3.25 shares Kokkos execution spaces with user kernels (`PetscGetKokkosExecutionSpace`, `DMDAVecGetKokkosOffsetView`); device-native preconditioners (`PCBJKOKKOS`) and Kokkos-Kernels back exascale PDE paths ([PETSc GPU roadmap](https://petsc.org/main/overview/gpu_roadmap/), [arXiv:2406.08646](https://arxiv.org/html/2406.08646v2)). **Li gap:** no KSP/SNES/DM/time-integrator surface; tier-2 physics uses shared C cores and package stubs — implicit/AMG/distributed mesh absent (**lic#117**, **lic#14**).

**Stdlib numerics / SIMD roadmaps.** C++26 `std::simd` (libstdc++ x86-first, permute/math incomplete) and Go 1.26 `simd/archsimd` (low-level intrinsics under `GOEXPERIMENT=simd`) show industry push for portable vector APIs atop compiler lowering. **Li gap:** PH-2i matrix `@` and PH-7e pure-Li SIMD matmul still partial; red tier-1 rows need compiler lowering (**lic#27**, **lic#33**).

**Kokkos vs OpenMP portability.** Kokkos/RAJA often lead empirical portability studies (P≈0.91 Kokkos vs ~0.45 prescriptive OpenMP on multi-vendor sets); OpenMPTarget can trail native CUDA/HIP (≈30–57% in cited Kokkos studies). **Li gap:** `std.execution.decorators` lacks memory spaces and backend selection — **lic#15**, **lic#109**.

**FFTW / vendor FFT roofline.** FFT intensity scales as O(log N); GPU FFT curves show compute-bound small N and memory-bound large N; vendor libs peak, FFTW autotune wins portability ([inverse roofline on GPU FFT](https://arxiv.org/pdf/1702.00629)). **Li gap:** no tier-1 pure-Li FFT proof path — **benchmarks#18**, **#52**, **#26**.
