- **HPC portability (P1):** Kokkos, PETSc, FFTW, hypre, RAJA, HPX marked **missing**; Eigen/OpenMP/SUNDIALS/stdpar **partial** — tier-2 physics still **9× shared_c_kernel** vs pure-Li path.
- **SOTA cadence (2024–2026):** **Eigen 5.0.0** (2025-09-30, SemVer + C++17 floor); **Kokkos 4.6.x** (4.6.0 Mar 2025 → 4.6.2 Jul 2025, graph `then` nodes, HIP `hipMallocAsync`); **PETSc 3.25** scheduled Mar 2026 with Kokkos GPU preconditioners (**PCBJKOKKOS**); **Chapel 2.4** (Mar 2025) stable + Python interop.
- **PETSc + Kokkos stack:** Exascale pattern = separate programming models, Kokkos-Kernels wrappers, **isolate CPU↔GPU sync**, profile GPU timelines — Li needs explicit **memory space + backend** rules before solver-class packages (**lic#28**, **lic#15**).
- **LLVM / G-par:** MLIR **`omp` dialect** gained composite **distribute+wsloop** lowering (Feb 2025), **canonical loop** ops + `omp.unroll_heuristic` (Jul 2025), **workdistribute** (Aug 2025) — concrete surfaces for **std/execution** → OpenMP (**lic#34**).
- **FFT catalog:** Community/vendor benches (gearshifft, MKL vs FFTW, hpk::fft 2025) support tier-1 FFT row + roofline harness (**benchmarks#18**, **#26**).
- **Competitive AI/HPC langs:** **Carbon p4880** (safety-first 2025 roadmap, 0.1 slipped to 2026) and **Mojo 1.0b** (LLVM + Python interop) reinforce Li differentiation via **`lic build` certificate** + **Vision-LLM** JSON — not optional polish.
