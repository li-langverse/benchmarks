### C. Web spot-check (2026-05-19)

**PETSc + Kokkos PDE stack.** Exascale practice couples PETSc KSP/SNES with Kokkos GPU preconditioners (`PCBJKOKKOS`); GPU wins need careful sync and profiling — CPU is not always faster. **Li gap:** no implicit/AMG/distributed mesh story; tier-2 uses shared C cores and physics stubs — **lic#14**, **lic#15**.

**Horner / polynomial SIMD.** Horner minimizes ops but serializes; Estrin + FMA/SIMD removes pipeline stalls and can yield large speedups on modern CPUs. **Li gap:** explains **~88.8×** vs autovec C++ for `horner_pure_li` — fix in PH-7e lowering + lexer (lic#47), not catalog threshold tweaks.

**Kokkos vs OpenMP portability.** Recent ports show Kokkos spanning more vendor GPU backends; hybrid OpenMP+Kokkos is common for hot operators. **Li gap:** `std.execution.decorators` is policy AST only — **lic#15**, **lic#34**.

**Stdlib numerics roadmaps.** NumPy NEPS, Rust SVE/SME goals, and JS stdlib BLAS tracks treat SIMD GEMM as baseline. **Li gap:** matrix `@` and SIMD matmul deferred (2i, 7e); near-threshold greens (~1.03×) need sustained numerics work — **lic#27**, **lic#33**.
